# Screen Recording

How I record a screen walkthrough, when a picture isn't enough and a video is worth ten thousand words.

- **Hack a video call**: start a solo Google Meet/Hangouts call, share your screen, and record it. No extra tool needed if recording calls is already a habit.
- **[Cap](https://cap.so)**: a dedicated screen recorder, good for a quick focused walkthrough.
- **[Loom](https://loom.com)**: same idea, widely used, easy to share a link afterward.

Any of these work -- pick whichever is already open. The point isn't the tool, it's making the recording rather than skipping it.
